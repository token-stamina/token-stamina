Privacy Policy

Last updated: 2026-10-28 (plugin version 0.5.1). Token Stamina is an independent, community-made plugin for Claude Code. It is not affiliated with Anthropic.

Token Stamina runs on your own machine as hooks and commands inside Claude Code. It has no server and no account. It collects no telemetry, makes no model calls of its own, and does not profile you. This page lists what it reads, what it writes and what can leave your machine.

What it reads
Only on your machine: the usage numbers Claude Code passes to the status line (rate limits, context size, session id, working folder); your session transcripts under ~/.claude/projects (usage per model, context size, what the last turn did, MCP and skill usage counts); the subagent metadata files Claude Code keeps there (description, agent type, model, finished flag) to count running subagents; and the text of each prompt, only to detect its language (the prompt text is not stored). The /token-stamina:audit command also counts the characters of your always-loaded files (CLAUDE.md, MEMORY.md), lists installed plugins, and reads MCP server names (no keys or values).
What it writes
Its own files go under ~/.claude/token-stamina/ (or the folder in TOKEN_STAMINA_HOME): state, caches, per-session bookkeeping, an append-only events.jsonl (session ids, token counts, which hint fired, subagent model decisions) and your config.json. Outside that folder it changes ~/.claude/settings.json (status line, auto-compact window) and optionally ~/.claude/keybindings.json only when you run /token-stamina:setup or /token-stamina:autocompact and agree; a backup of settings.json is saved first.
Handoff notes
To survive a /compact or /clear, it saves a short note in ~/.claude/token-stamina/handoff/: the working folder path and session id, up to the last three requests (each clipped to 200 characters), commit subjects, edited file paths and to-do items. Notes older than 7 days are deleted the next time the Stop hook runs. Set "handoff": false in ~/.claude/token-stamina/config.json to stop writing and restoring notes (existing notes are not deleted; remove the folder to delete them). Restored notes and hint lines are added to the conversation, so Claude Code sends them to the model like any other context.
Network
At most once a day, one HTTPS GET of https://raw.githubusercontent.com/token-stamina/token-stamina/main/.claude-plugin/plugin.json to see whether a newer version exists. Nothing is sent beyond the request itself (GitHub sees your IP address, as with any download). "updateCheck": false turns it off. Two things the plugin can start may use the network on their own: claude plugin list during an audit, and a status line command you asked it to wrap.
Optional board
The efficiency board is optional and only works after you set it up in the Claude desktop app. When you run /token-stamina:board, Claude writes board rows (numbers, model names, the last folder name of each session's working folder), session titles (unless "dashboardMaskTitles": true) and your usage percentages to a private Artifact that you published under your own claude.ai account. Token Stamina operates no server and receives none of this. Without a dashboardUrl in your config, nothing is pushed. "board": false stops the local rows.
What it does not do
No telemetry, no analytics, no advertising, no sale or sharing of data, no calls to any language model from its scripts, and no profiling. It does not send your transcripts, prompts or files anywhere.
Removing your data
Uninstall the plugin, delete ~/.claude/token-stamina/, and remove statusLine and env.CLAUDE_CODE_AUTO_COMPACT_WINDOW from ~/.claude/settings.json (or restore the settings.json.bak-token-stamina-* backup). Delete the board Artifact in claude.ai if you created one.
Contact
Questions or concerns: open an issue on GitHub. Changes to this policy are published on this page and in the repository history.
