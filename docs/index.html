Make your weekly limit last until the reset.

Token Stamina is a Claude Code plugin that shows, in your status line, how much of your weekly and 5-hour limits you've used against how much of each window has passed. Fall well behind pace and it moves subagents to cheaper models; when your context gets long, it tells you when a compact would help. It makes no LLM calls. Its only network request is a once-a-day version check, which you can turn off.

claude · ~/work/api
> refactor the billing client and add tests ✓ 4 files edited · committed "split billing client"
~/work/api main │7d 62%·today 5.4% ·reset Mon 15:00·ctx 41%

    01When you're ahead of pace

    1. Subagent model. auto While the grade is red, a subagent call with no model set goes to Haiku if the task looks simple and to Sonnet otherwise. If the call names a model, is a fork, or looks like review or design work, it's left alone. You can change this to suggestions only, or turn it off.
    2. Handoff note. auto Before you compact or clear, it saves the last few requests, commits, edited files and to-dos, and adds them to the new conversation. The note is put together from your transcript; no model writes it. You can compact early and not have to explain again where you were.
    3. Compact suggestion. one click Once the conversation is large and you've just finished something (a commit, an edit, an answer), it suggests /compact with the commit subjects filled in. If the conversation is much larger than that, it suggests a new session instead.
    4. Auto-compact point. set once Setup can lower Claude Code's automatic compact point, so a long session doesn't keep re-reading a very large context on every call.
    5. Grade change. once When the grade changes, Claude gets one short line and tells you, in your language. Other prompts get nothing.

    It doesn't change the model of your main conversation, block requests, or compact by itself. Claude Code doesn't let plugins run /compact. /token-stamina:audit lists what gets loaded into every conversation, such as CLAUDE.md files, plugins and MCP servers you never use. It only reports and doesn't change anything.

    02How the grade works

    The status line shows the numbers Claude Code already passes to it, plus the grade.

    ~/work/api  main  │  7d 84% · today 5.3% ● · reset Mon 15:00 · ctx 41%
    7d 84%
    weekly limit used, as reported by Claude Code
    today 5.3%
    what you can use per day from now and still make it to the reset
    ●
    grade: green, yellow or red
    reset Mon 15:00
    when the weekly window resets
    ctx 41%
    how full this conversation is

    60% used on Saturday is fine. 60% on Monday isn't. So the grade compares usage with time. Green if usage is at or below the share of the week that's gone. Yellow if it's up to 10 points over. Red if it's more than 10 points over, or above 90% at any point. The weekly and 5-hour windows are graded separately and you see the worse one.

    03Install

    1In a terminal:

    claude plugin marketplace add token-stamina/token-stamina
claude plugin install token-stamina@token-stamina

    2Then in Claude Code:

    /token-stamina:setup

    A plugin can't set the status line by itself, so setup asks before it changes ~/.claude/settings.json. If you already have a status line, it can keep yours and add to it.

    Or do step 1 inside Claude Code

    Run these one at a time, then run setup:

    /plugin marketplace add token-stamina/token-stamina
    /plugin install token-stamina@token-stamina

    04What runs on your machine

    Reads
    The usage numbers Claude Code passes to the status line, and your session transcripts under ~/.claude/projects, to add up usage and build the handoff note.
    Writes
    Only to ~/.claude/token-stamina/, and to your settings file during setup if you agree. Handoff notes are deleted after seven days.
    Never
    Its scripts send no telemetry and call no model. Their only network request is the update check: once a day at most, one download of the published version number from GitHub, so it can tell you when a new version is out ("updateCheck": false turns it off). Two commands it can start may go online: claude plugin list during an audit, and a status line command you've asked it to wrap.

    The full file-by-file list is in the README. To remove everything, uninstall the plugin and delete that folder.
