Make your weekly limit last until the reset.

Token Stamina is a small plugin for Claude Code. When you're spending faster than the clock, it steps in: subagents drop to cheaper models, finished work gets a one-click compact that keeps your place, and you hear about it once, not on every prompt. When you're on pace, it stays out of the way. No LLM calls, no network connections.

week 43% gone · limit 41% used

Nothing happens. The status line shows a green dot and that's all.

Tuesday, ahead of pace

week 43% gone · limit 62% used

  • autoYour place is saved before a compact and put back after.
  • one clickWhen a task wraps up, /compact is offered with the commit subjects filled in.
  • onceOne line tells you the grade changed.

01What it does when you're ahead of pace

  1. Cheaper subagents, automatically. auto While the grade is red, a subagent call that doesn't name a model goes to Haiku for simple work or Sonnet otherwise. Calls that name a model, forks, and anything that looks like a judgment task are left alone. You can switch this to suggestions only, or off.
  2. Compact early without losing your place. auto Before you compact or clear, it writes down the last few requests, commits, edited files and to-dos, and puts them back afterwards. No model writes the note; it's assembled from your transcript. That makes the cheap move, starting lighter, a safe one.
  3. The right moment, offered once. one click When the conversation is large and a piece of work is done (a commit, an edit, an answer), it suggests /compact with the commit subjects already filled in, or a fresh session if you've gone very far.
  4. An earlier auto-compact, if you want it. set once Setup can move Claude Code's automatic compact point earlier, so long sessions stop re-reading a huge context on every call.
  5. A heads-up, not a nag. once One short line when the grade changes. Claude passes it on in your language.

What it won't do: switch the model of your main conversation, block a request, or compact on its own. Claude Code doesn't let plugins run /compact, so that stays your click. There's also /token-stamina:audit, which lists what is loaded into every conversation (CLAUDE.md files, plugins, MCP servers you never use) and changes nothing.

02How it decides

It lives in your status line and reads the usage numbers Claude Code already passes there.

~/work/api  main  │  7d 84% · today 5.3% ● · reset Mon 15:00 · ctx 41%
7d 84%
share of the weekly limit used, straight from Claude Code
today 5.3%
how much you can spend per day from here and still last until the reset
●
the pace grade: green, yellow or red
reset Mon 15:00
when the weekly window rolls over
ctx 41%
how full the current conversation is

A percentage on its own doesn't tell you much. 60% used is fine on Saturday and a problem on Monday. So the grade looks at both numbers: if you've used no more than the share of the week that has passed, you're green. Up to ten points ahead is yellow. Beyond that, or past 90% at any time, is red. The weekly and 5-hour windows are graded separately, and the worse of the two is the one you see.

03Install

Two steps.

1In your terminal, install the plugin:

claude plugin marketplace add token-stamina/token-stamina
claude plugin install token-stamina@token-stamina

2Start Claude Code and run setup:

/token-stamina:setup

Plugins can't register the status line by themselves, so setup asks before it edits ~/.claude/settings.json. If you already have a status line, Token Stamina can wrap it instead of replacing it. Messages come in English, Korean and Japanese.

Rather do step 1 inside Claude Code?

Type these one at a time, then run setup as above:

/plugin marketplace add token-stamina/token-stamina
/plugin install token-stamina@token-stamina

04What runs on your machine

Reads
The usage numbers Claude Code passes to the status line, and your local session transcripts under ~/.claude/projects, to add up usage and build the handoff note.
Writes
Only to ~/.claude/token-stamina/, plus your settings file during setup if you agree. Handoff notes older than seven days are deleted.
Never
Network requests, telemetry, or calls to any model from its own scripts. Two things it starts can go online on their own: claude plugin list during an audit, and a status line command you choose to wrap.

The full list, file by file, is in the README. To remove everything, uninstall the plugin and delete that folder.
