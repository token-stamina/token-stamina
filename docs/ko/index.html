주간 한도, 리셋 전에 바닥나지 않게.

Token Stamina 는 Claude Code 플러그인입니다. 주간·5시간 한도를 얼마나 썼는지, 각 창의 시간이 얼마나 지났는지를 상태줄에 나란히 보여 줍니다. 속도보다 많이 앞서 쓰면 하위 에이전트를 더 싼 모델로 돌리고, 대화가 길어지면 압축할 때를 알려 줍니다. LLM을 부르지 않습니다. 네트워크 요청은 하루 한 번 새 버전을 확인하는 것뿐이며, 끌 수 있습니다.

claude · ~/work/api
> refactor the billing client and add tests ✓ 4 files edited · committed "split billing client"
~/work/api main │7d 62%·today 5.4% ·reset Mon 15:00·ctx 41%

    01하는 일

    1. 하위 에이전트 모델. 자동 등급이 빨강인 동안, 모델을 지정하지 않은 하위 에이전트 호출은 단순한 일이면 Haiku로, 아니면 Sonnet으로 갑니다. 모델을 지정했거나, 포크이거나, 검토·설계처럼 판단이 필요한 일로 보이면 건드리지 않습니다. 제안만 하도록 바꾸거나 끌 수도 있습니다.
    2. 인계 메모. 자동 턴이 끝날 때마다 최근 요청 몇 개, 커밋, 고친 파일, 할 일 목록을 저장해 두고, 압축하거나 비운 뒤 새 대화에 다시 넣습니다. 메모는 대화 기록에서 뽑아 만들 뿐 모델이 쓰지 않습니다. 그래서 일찍 압축해도 어디까지 했는지 다시 설명할 필요가 없습니다.
    3. 압축 제안. 제안 대화가 커졌고 방금 뭔가를 끝냈으면(커밋, 수정, 답변) 커밋 제목을 채운 /compact를 권합니다. 대화가 그보다 훨씬 크면 새 세션을 권합니다.
    4. 자동 압축 시점. 한 번 설정 setup에서 Claude Code의 자동 압축 시점을 앞당길 수 있습니다. 그러면 긴 세션이 호출할 때마다 아주 큰 맥락을 다시 읽지 않습니다.
    5. 등급 변화. 한 번 등급이 바뀌면 Claude에게 짧은 한 줄이 가고, Claude가 그걸 사용자의 언어로 전합니다. 등급이 그대로면 아무것도 붙지 않습니다.

    메인 대화의 모델을 바꾸거나 요청을 막지 않습니다. 스스로 압축하지도 않는데, Claude Code가 플러그인의 /compact 실행을 막아 두었기 때문입니다. /token-stamina:audit는 모든 대화에 실리는 것들(CLAUDE.md 파일, 플러그인, 안 쓰는 MCP 서버 등)을 보여 줍니다. 보여 주기만 하고 아무것도 바꾸지 않습니다.

    02등급은 이렇게 정합니다

    상태줄에는 Claude Code가 이미 넘겨주는 숫자와 등급이 보입니다.

    ~/work/api  main  │  7d 84% · today 5.3% ● · reset Mon 15:00 · ctx 41%
    7d 84%
    주간 한도 사용량(Claude Code가 알려 주는 값)
    today 5.3%
    지금부터 하루에 이만큼씩 쓰면 리셋까지 버틸 수 있습니다
    ●
    등급: 초록·노랑·빨강
    reset Mon 15:00
    주간 한도가 리셋되는 시각
    ctx 41%
    지금 대화가 얼마나 찼는지

    리셋까지 하루 남기고 60%면 괜찮습니다. 이틀째에 60%면 문제입니다. 그래서 등급은 사용량을 시간과 비교합니다. 지난 시간만큼 이하로 썼으면 초록, 10포인트까지 넘으면 노랑, 10포인트보다 더 넘거나 언제든 90% 이상이면 빨강입니다. 주간과 5시간 한도를 따로 매기고, 둘 중 나쁜 쪽이 보입니다.

    03설치

    1터미널에서:

    claude plugin marketplace add token-stamina/token-stamina
claude plugin install token-stamina@token-stamina

    2그다음 Claude Code에서:

    /token-stamina:setup

    플러그인은 상태줄을 스스로 등록할 수 없어서, setup이 ~/.claude/settings.json을 고치기 전에 먼저 물어봅니다. 이미 쓰는 상태줄이 있으면 그대로 두고 덧붙일 수 있습니다.

    1단계를 Claude Code 안에서 하려면

    하나씩 실행한 다음 setup을 실행합니다.

    /plugin marketplace add token-stamina/token-stamina
    /plugin install token-stamina@token-stamina

    04내 컴퓨터에서 하는 일

    읽는 것
    Claude Code가 상태줄에 넘겨주는 사용량 숫자와 ~/.claude/projects 아래 세션 기록입니다. 사용량을 합산하고 인계 메모를 만드는 데 씁니다.
    쓰는 것
    ~/.claude/token-stamina/ 안에만 씁니다. setup 때 동의하면 설정 파일도 고칩니다. 인계 메모는 7일 뒤 지워집니다.
    하지 않는 것
    스크립트는 사용 통계 전송과 모델 호출을 하지 않습니다. 네트워크 요청은 업데이트 확인 하나뿐입니다. 하루에 많아야 한 번, GitHub에서 공개된 버전 번호만 받아 와 새 버전이 나오면 알려 줍니다("updateCheck": false로 끕니다). 다만 실행하는 명령 두 개는 스스로 인터넷에 접속할 수 있습니다. 점검할 때 쓰는 claude plugin list와, 감싸 달라고 지정한 상태줄 명령입니다. 대화에 붙이는 힌트 줄과 인계 메모는 다른 대화 내용과 마찬가지로 모델에 전송됩니다.

    파일별 전체 목록은 README(영어)에 있습니다. 모두 지우려면 플러그인을 제거하고 그 폴더를 지우면 됩니다.

    Token Stamina는 무료입니다. 토큰을 아끼는 데 도움이 됐다면 커피 한 잔 사 주셔도 좋습니다.

    Token Stamina는 독립 커뮤니티 프로젝트입니다. Anthropic과 제휴 관계가 아니고, Anthropic의 보증이나 후원도 받지 않습니다. "Claude"와 "Claude Code"는 Anthropic, PBC의 상표이고, 여기서는 이 플러그인이 무엇과 함께 쓰이는지 밝히는 데만 씁니다. 7d·5h 수치는 Claude Code에서 오고, 등급·하루 몫·절약 수치는 내 컴퓨터에서 낸 추정치입니다. 청구 금액이 아닙니다.
