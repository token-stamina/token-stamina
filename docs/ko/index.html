    등급과 상관없이 늘 동작합니다: 턴이 끝날 때마다 인계 메모를 저장해 압축·비우기 뒤에 다시 넣고, 대화가 길어지면 /compact 를 권합니다.

    01하는 일

    하위 에이전트 모델

    자동

    속도보다 앞서 쓰면, 모델을 지정하지 않은 하위 에이전트를 Haiku나 Sonnet으로 돌립니다.

    자세히

    등급이 빨강인 동안, 모델을 지정하지 않은 하위 에이전트 호출은 단순한 일이면 Haiku로, 아니면 Sonnet으로 갑니다. 하위 에이전트나 세션이 한꺼번에 여럿 돌고 있으면 노랑에서도 그렇게 합니다. 모델을 지정했거나, 포크이거나, 검토·설계처럼 판단이 필요한 일로 보이면 바꾸지 않고, 많아야 Claude에게 제안만 갑니다. 제안만 하도록 바꾸거나 끌 수도 있습니다.

    인계 메모

    자동

    턴이 끝날 때마다 하던 자리를 저장해 두고, 압축·비우기 뒤에 다시 넣습니다.

    자세히

    턴이 끝날 때마다 최근 요청 몇 개, 커밋, 고친 파일, 할 일 목록을 저장해 두고, 압축하거나 비운 뒤(데스크탑 앱의 비우기 포함) 새 대화에 다시 넣습니다. 메모는 대화 기록에서 뽑아 만들 뿐 모델이 쓰지 않습니다. 비운 뒤에는 마지막 몇 턴을 화면에만 보여 주고 모델에는 보내지 않습니다. 그래서 일찍 압축해도 어디까지 했는지 다시 설명할 필요가 없습니다.

    압축 제안

    제안

    긴 대화에서 일을 막 끝냈을 때 /compact를 권합니다.

    자세히

    대화가 커지면 Claude가 일을 마칠 때 /compact를 권하도록 합니다(데스크탑 앱에서는 버튼 카드). 대화가 그보다 훨씬 크면 새 세션을 권합니다. 더 커지면 짧은 주제 확인 줄이 붙어, 다음 요청이 다른 주제일 때 Claude가 비우기를 제안합니다.

    자동 압축 시점

    한 번 설정

    setup에서 자동 압축 시점을 앞당겨, 긴 세션이 덜 다시 읽게 합니다.

    자세히

    setup에서 Claude Code의 자동 압축 시점을 앞당길 수 있습니다. 그러면 긴 세션이 호출할 때마다 아주 큰 맥락을 다시 읽지 않습니다.

    등급 변화

    한 번

    등급이 바뀔 때만 한 줄을 사용자의 언어로 알립니다. 그대로면 조용합니다.

    자세히

    등급이 바뀌면 Claude에게 짧은 한 줄이 가고, Claude가 그걸 사용자의 언어로 전합니다. 등급이 그대로면 아무것도 붙지 않습니다.

    보고

    요청할 때

    명령 네 개로 사용량, 예상 절약, 고정 비용, 돌고 있는 하위 에이전트를 봅니다.

    자세히

    내 컴퓨터의 대화 기록과 플러그인 자체 기록을 읽어 표로 보여 줄 뿐, 모델을 부르지 않습니다. 절약 수치는 추정치이고 청구 금액이 아닙니다.

    메인 대화의 모델을 바꾸거나 요청을 막지 않습니다. 스스로 압축하지도 않는데, Claude Code가 플러그인의 /compact 실행을 막아 두었기 때문입니다. 상태줄은 플러그인이 직접 그리고, 상태줄 설정은 건드리지 않습니다.

    지금 대화가 얼마나 찼는지

    리셋까지 하루 남기고 60%면 괜찮습니다. 이틀째에 60%면 문제입니다. 그래서 등급은 사용량을 시간과 비교합니다. 지난 시간만큼 이하로 썼으면 초록, 10포인트까지 넘으면 노랑, 10포인트보다 더 넘거나 언제든 90% 이상이면 빨강입니다. 주간과 5시간 한도를 따로 매기고, 둘 중 나쁜 쪽이 보입니다.

    03설치

    Claude Code 2.1.308 이상이 필요합니다. 그보다 낮으면 먼저 claude update를 실행합니다. Node.js는 필요 없습니다.

    1터미널에서 마켓플레이스를 추가합니다:

    claude plugin marketplace add token-stamina/token-stamina

    2이어서 플러그인을 설치합니다(마켓플레이스 추가만으로는 설치되지 않습니다):

    claude plugin install token-stamina@token-stamina

    3Claude Code 새 세션을 엽니다(이미 열려 있던 세션은 플러그인을 못 봅니다). 첫 답이 나온 뒤 상태줄이 보입니다. 따로 설정할 것은 없습니다.

    선택: /token-stamina:setup은 힌트 언어를 정하고, 0.5.x가 남긴 상태줄 항목을 정리하고, 자동 압축 시점을 제안합니다. 파일을 고치기 전에 바뀔 내용을 먼저 보여 주고 동의를 기다립니다. 나중에 업데이트하려면 claude plugin update token-stamina@token-stamina를 실행하고 Claude Code를 다시 시작합니다.

    1·2단계를 Claude Code 안에서 하려면

    하나씩 실행한 다음 새 세션을 엽니다.

    /plugin marketplace add token-stamina/token-stamina
    /plugin install token-stamina@token-stamina

    04명령

    모두 내 컴퓨터의 파일로 표를 보여 줍니다. 모델을 부르지 않고 아무것도 바꾸지 않습니다.

    /ts-report
    모델별 사용량, 메인 대화와 하위 에이전트 비교. 기본은 최근 30일, 또는 --since YYYY-MM-DD.
    /ts-savings
    플러그인 덕에 아꼈을 토큰. 추정치이고 청구 금액이 아닙니다. 플러그인 자체 기록을 읽기 때문에 0.6.0 이전의 절약은 같은 방식으로 세지 않습니다.
    /ts-audit
    모든 대화에 실리는 것: 늘 읽히는 파일, 플러그인, MCP 서버와 스킬, 그리고 끌 만한 후보.
    /ts-fleet
    지금 돌고 있는 하위 에이전트, 모델별.

    /token-stamina:autocompact는 Claude Code가 스스로 압축하는 시점(300k, 400k, 600k, 기본값)을 고릅니다. 바뀔 내용을 먼저 보여 주고 묻습니다.

    05내 컴퓨터에서 하는 일

    읽는 것
    Claude Code가 알려 주는 세션 사용량 숫자와 ~/.claude/projects 아래 세션 기록입니다. 사용량을 합산하고 인계 메모를 만드는 데 씁니다. 돌고 있는 하위 에이전트를 세려고 Claude Code가 그 아래 남기는 하위 에이전트 파일도 읽습니다.
    쓰는 것
    ~/.claude/token-stamina/ 안에만 씁니다. setup 때 동의하면 설정 파일도 고칩니다. 인계 메모에는 최근 요청을 짧게 자른 글이 들어가고, 자동으로 지워지지 않습니다. 지우려면 그 폴더를 지웁니다.
    하지 않는 것
    네트워크 요청, 사용 통계 전송, 모델 호출, 다른 명령 실행을 하지 않습니다. 대화에 붙이는 힌트 줄과 인계 메모는 다른 대화 내용과 마찬가지로 모델에 전송됩니다.

    파일별 전체 목록은 README(영어)에 있습니다. 모두 지우려면 플러그인을 제거하고 그 폴더를 지우면 됩니다.

    Token Stamina는 무료입니다. 토큰을 아끼는 데 도움이 됐다면 커피 한 잔 사 주셔도 좋습니다.

    Token Stamina는 독립 커뮤니티 프로젝트입니다. Anthropic과 제휴 관계가 아니고, Anthropic의 보증이나 후원도 받지 않습니다. "Claude"와 "Claude Code"는 Anthropic, PBC의 상표이고, 여기서는 이 플러그인이 무엇과 함께 쓰이는지 밝히는 데만 씁니다. 7d·5h 수치는 Claude Code에서 오고, 등급·하루 몫·절약 수치는 내 컴퓨터에서 낸 추정치입니다. 청구 금액이 아닙니다.
